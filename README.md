## 接线方法

### I2C1 总线 — MAX30102 + MPU6050（PB6/PB7）

两个传感器共享 I2C1 总线，引脚并联：

```
STM32 PB6 ───┬─── MAX30102 SCL
             └─── MPU6050 SCL

STM32 PB7 ───┬─── MAX30102 SDA
             └─── MPU6050 SDA

3.3V   ───┬─── MAX30102 VIN
          └─── MPU6050 VCC

GND    ───┬─── MAX30102 GND
          └─── MPU6050 GND
```

I2C1 设备地址（程序中定义，不可冲突）：

| 设备     | 7-bit 地址 | 8-bit 写地址     |
|---------|-----------|-----------------|
| MAX30102| 0x57      | 0xAE            |
| MPU6050 | 0x68      | 0xD0            |

### I2C2 总线 — SSD1306 OLED（PB10/PB11）

OLED 独占 I2C2 总线，避免与 100Hz 高速采样的 MAX30102 竞争带宽：

```
STM32 PB10 ──── SSD1306 SCL
STM32 PB11 ──── SSD1306 SDA
3.3V       ──── SSD1306 VCC
GND        ──── SSD1306 GND
```

| 设备     | 7-bit 地址 | 8-bit 写地址     |
|---------|-----------|-----------------|
| SSD1306 | 0x3C      | 0x78            |

**重要**: PB6、PB7、PB10、PB11 各需要一个 4.7kΩ 电阻上拉到 3.3V。I2C 空闲时 SCL/SDA 应为 3.3V（高电平），如果为 0V 说明上拉电阻虚焊或某设备将总线拉死。

### UART1 — HC-05 蓝牙模块

```
STM32 PA9  ──── HC-05 RX
STM32 PA10 ──── HC-05 TX
3.3V       ──── HC-05 VCC
GND        ──── HC-05 GND
```

HC-05 工作于 3.3V 逻辑电平，与 STM32 直连无需电平转换。蓝牙默认波特率 9600。

### UART2 — ASR PRO 语音识别

```
STM32 PA2  ──── ASR PRO RX（或 SU-03T 的 B6/B7，取决于固件配置）
STM32 PA3  ──── ASR PRO TX
5V         ──── ASR PRO VCC（注意：语音模块通常是 5V 供电）
GND        ──── ASR PRO GND
```

> ASR PRO 模块通常工作在 5V，但它的 TX 引脚输出一般是 3.3V 电平，可直接接 STM32。
> 如果不确定，用万用表测量模块 TX 引脚的逻辑高电平电压，超过 3.6V 则需串联一个 1kΩ 电阻。

### DS18B20 温度传感器 — 1-Wire

```
                                ┌──────┐
                                │DS18B20│
                                │ (正面)│
DS18B20 引脚:                    │1 2 3 │
  1 = GND  ──── GND              └─┬──┬─┘
  2 = DQ   ──── STM32 PA0          │  │
  3 = VCC  ──── 3.3V            ┌─┘  └─┐
                                 │     │
                            PA0 接引脚2

           3.3V
            │
           ┌┴┐
           │ │ 4.7kΩ  ← 必需！PA0 与 3.3V 之间
           │ │
           └┬┘
            │
            └──── PA0 (DS18B20 DQ)
```

> PA0 用作 1-Wire；PB10 已分配给 I2C2 SCL（OLED），故 DS18B20 不使用 PB10。

如果使用**寄生供电模式**，DS18B20 的 VCC 和 GND 都接地，但程序用的是外部供电（0xCC Skip ROM 命令后跟 0x44），所以**必须三线制接法**（VCC、DQ、GND 全部接上），不能只用两线。

> 代码中 `DS18B20_ReadTemp` 返回 `-999.0f` 表示 CRC 校验失败（接触不良或线太长时会出现），`main.c` 已处理此异常（>-900 才显示）。

### DS1302 RTC 时钟模块

```
STM32 PB1  ──── DS1302 CLK
STM32 PB12 ──── DS1302 DAT
STM32 PB9  ──── DS1302 RST（模块上标注为 RST/CE）
3.3V       ──── DS1302 VCC
GND        ──── DS1302 GND
```

DS1302 模块板上已经有上拉电阻和晶振（32.768kHz），无需外接组件。安装 CR2032 纽扣电池后，断电也不会走时丢失。

### 按键 — PE3、PE4

两个按键，分别控制向前翻页和向后翻页：

```
STM32 PE4 ────┬──── 按键一脚 (向前翻页)
              │
GND      ────┴──── 按键另一脚

STM32 PE3 ────┬──── 按键一脚 (向后翻页)
              │
GND      ────┴──── 按键另一脚
```

按下 → 对应引脚读为低电平（内部上拉），程序做了 20ms 消抖和 300ms 防连按。

## 首次使用步骤

1. 接好所有模块的电源线和信号线。
2. 逐个模块上电验证（先把 I2C 之外的模块一个个通电，最后再接 OLED/MPU6050/MAX30102）。
3. 用 ST-Link 或串口下载程序到 STM32F103。
4. 上电后 OLED 应显示 **HeartRate: 0 bpm**。
5. 把手指放到 MAX30102 传感器上稳定 10 秒以上，心率数据会逐渐出现。
6. 把 DS18B20 贴在手腕皮肤上，体温数据约 30 秒后出现在第 3 页。
7. 手机打开蓝牙，搜索并配对 HC-05（默认名称为 HC-05，配对码 1234）。
8. 在手机蓝牙串口 APP 上连接，每 1 秒会收到 JSON 数据推送。

## 操作说明

### 页面切换

显示屏共 5 个页面，按硬件按键（PE4 翻下页、PE3 翻上页）或发送语音命令切换：

| 页码 | 显示内容             | 说明                            |
|------|---------------------|---------------------------------|
| 1    | 心率（HeartRate）    | 单位 bpm，手指需稳定放在传感器上    |
| 2    | 血氧（SpO2）         | 单位 %，正常值 95–100            |
| 3    | 步数（Steps）        | 走路时自动累计                   |
| 4    | 体温（BodyTemp）     | 补偿后的体表估计温度，单位 °C      |
| 5    | 时间（Time）         | HH:MM:SS，由 DS1302 RTC 提供    |

### FreeRTOS 任务说明

程序中 4 个 FreeRTOS 任务各自负责不同功能：

| 任务名    | 堆栈  | 周期  | 功能                                   |
|----------|------|------|----------------------------------------|
| Sensors  | 512  | 200ms| 读取 MAX30102、MPU6050、DS18B20；计算 HR/SpO2/Steps/Temp |
| Display  | 512  | 50ms | 刷新 OLED 屏幕，处理按键切换页面 (PE4/PE3)  |
| Voice    | 384  | 100ms| 轮询 ASR PRO 语音识别指令               |
| BT       | 384  | 20ms | 处理蓝牙 AT 命令，每 2 秒上报 JSON 数据    |

### 心率血氧使用方式

MAX30102 传感器需要手指**稳定按压**在 LED 上，不能移动：
- 手指略施压力，覆盖光电传感器窗口
- 保持静止至少 10 秒不动
- 心率在稳定后约 5-8 秒更新一次
- 手指抖动或压力不均会导致数据不准或显示 0

> 心率和血氧计算基于 IR/Red 光的 AC/DC 比值。程序使用 100Hz 采样率，
> 带通滤波（HP 0.5Hz + LP 5Hz）提取脉搏波形，动态阈值检测峰值。

### 计步器使用方式

基于 MPU6050 加速度数据自动识别：
- 将设备佩戴在手腕上正常走路即可
- 通过加速度幅值减去重力分量检测步态
- 自适应阈值：静止时阈值自动调低，运动时自动调高
- 最小步间隔 250ms（约 240 步/分钟上限）

### 温度传感器使用方式

DS18B20 需要贴在手腕皮肤上：
- TO-92 封装金属面朝皮肤
- 可用医用胶带固定
- 读取频率约每 800ms 一次（4 × 200ms 传感器任务周期）
- CRC 校验失败时返回 -999°C，程序会丢弃并显示 "--.- C"
- 体温补偿算法：根据 MPU6050 板级温度（作为环境温度参考）自动调整皮肤到核心的温差补偿量

## 蓝牙数据格式

HC-05 每 **2 秒** 自动上报一条 JSON，格式如下：

```json
{"hr":72,"spo2":98,"steps":1234,"temp":36.50}
```

| 字段   | 含义     | 单位  |
|-------|---------|------|
| hr    | 心率     | bpm  |
| spo2  | 血氧     | %    |
| steps | 步数     | 步   |
| temp  | 体温     | °C   |

> 体温无效时 temp 值为 0.00。

## 蓝牙设置命令

通过蓝牙串口 APP 发送以下命令（每条以换行结尾）：

### 设置时钟

```
TIME 14:30:00 21/05/26
```

格式：`TIME HH:MM:SS DD/MM/YY`（年取后两位）

### 校准血氧

```
CAL 110 25
```

格式：`CAL A B`

血氧公式：`SpO2 = A - B × R`，其中 `R = (AC_red/DC_red) / (AC_ir/DC_ir)`

默认值 A=110, B=25。如果需要更精确的血氧读数，可用标准血氧仪对比后调整这两个参数。

### AT 命令（需要 HC-05 进入 AT 模式）

HC-05 上电初始化时自动尝试 9600 波特率发送 `AT\r\n`，若收到 `OK` 则确认连接。如果需要修改 HC-05 参数（名称、配对码、波特率等），让 HC-05 在未配对状态下上电（STATE 灯慢闪），然后用 USB-TTL 直接连 HC-05 发送 AT 命令。

## 运动识别

程序通过 MPU6050 加速度数据自动分类佩戴者的运动状态：

| 状态     | 判定条件                            |
|---------|------------------------------------|
| WALKING | 步频 40–120 步/分钟，最近 2 秒内有步数 |
| RUNNING | 步频 > 120 步/分钟，最近 2 秒内有步数   |
| SHAKING | 无步数持续 2 秒以上且晃动能量 > 400     |
| UNKNOWN | 无步数且晃动幅度小，静止/待机状态         |

运动状态目前仅在语音命令 "查看状态" 时显示到屏幕。

## 常见问题

**Q: OLED 不显示**

A: OLED 使用 I2C2 总线（PB10/PB11），检查这两个引脚的 4.7kΩ 上拉电阻是否焊接。用万用表测量，SCL/SDA 在空闲时应为 3.3V（高电平）。如果为 0V，说明上拉电阻虚焊或 I2C 器件将总线拉死。

**Q: 心率一直显示 0**

A: 手指需要**完全覆盖** MAX30102 的 LED 和光电二极管窗口，保持静止。检查 MAX30102 板上的红光 LED 是否有微弱红光闪烁（表示激光正常点亮）。如果没有，说明 I2C 通信失败或模块未初始化成功。

**Q: 血氧显示固定 50 或 100**

A: 血氧计算公式中的 R 值超出了合理范围（因为 IR/Red 信号质量不足导致）。手指压力太大或太小都可能造成。尝试调整手指按压的力度——以刚好遮挡光为佳，不要太用力。

**Q: 体温波动大**

A: DS18B20 是接触式传感器，需要与皮肤连续紧密接触。如果贴得不紧或中间有空气间隙，会受到环境气温的显著影响。建议用医用胶带贴紧。

**Q: HC-05 连不上手机**

A:
1. HC-05 STATE 灯是否为慢闪（等待配对）？
2. 如果常亮，说明它已连到另一个设备，需要断开已有连接。
3. 如果快闪（每秒两次），说明已进入 AT 模式，需要重新上电。
4. 必须按住 HC-05 模块上的小按键不放再上电，才能进入 AT 模式修改参数。

**Q: ST-Link 下载后程序不运行**

A: 检查 BOOT0 跳线是否为 0（GND）。BOOT0=1 时进入串口下载模式，不会执行 Flash 中的程序。下载完成后将 BOOT0 接回 GND 并复位。

**Q: 堆栈溢出**

A: 程序在 `vApplicationStackOverflowHook` 中通过 UART1 输出 "STACK OVERFLOW: <任务名>"。用 USB-TTL 接 PA9 查看。如果出现此信息，需增大对应任务的堆栈大小（[main.c](main.c) 中 `xTaskCreate` 的第 3 个参数）。

**Q: MAX30102 FIFO 溢出**

A: `vTaskSensors` 每 200ms 读取一次 MAX30102。100Hz × 0.2s = 20 个样本。MAX30102 FIFO 容量 32 个样本，留有约 60% 余量。如果操作系统延时抖动导致读取超过 320ms 间隔，可能丢样本（老的会被跳过），但不影响当前输出。
