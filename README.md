# 智能健康手环 — STM32F103ZE + FreeRTOS

[![CI](https://github.com/Fearless-lucky/smart-health-band/actions/workflows/ci.yml/badge.svg?branch=Simple)](https://github.com/Fearless-lucky/smart-health-band/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

基于 STM32F103ZE 与 FreeRTOS 的可穿戴健康监测设备：

- **心率 / 血氧**：MAX30102 100Hz PPG 采样，0.5–5Hz IIR 带通 + 动态阈值峰值检测 + R 比值法 SpO2 估算
- **计步 / 运动识别**：MPU6050 加速度，自适应阈值 + 步态确认，分类 RESTING / WALKING / RUNNING
- **体温**：DS18B20 皮肤温度 + 环境温度补偿（CRC-8 校验）
- **显示**：SSD1306 OLED，6 页界面，按键 / 语音翻页
- **语音控制**：ASR PRO 模块 UART 单字节指令，经 FreeRTOS 队列送显示任务
- **蓝牙遥测**：HC-05 每 2 秒广播 JSON 健康数据
- **可靠性**：双 I2C 总线互斥、I2C 总线自恢复、独立看门狗 (4s)、栈溢出诊断、空闲 WFI 休眠

算法层不依赖硬件，配有[主机端单元测试](tests/)（合成 PPG/加速度信号验证心率、血氧、计步、温度补偿），CI 自动运行。

## 接线方法

### I2C1 总线 — MAX30102 + MPU6050（PB8/PB9）

两个传感器共享 I2C1 总线，引脚并联：

```
STM32 PB8 ───┬─── MAX30102 SCL
             └─── MPU6050 SCL

STM32 PB9 ───┬─── MAX30102 SDA
             └─── MPU6050 SDA

3.3V   ───┬─── MAX30102 VIN
          └─── MPU6050 VCC

GND    ───┬─── MAX30102 GND
          └─── MPU6050 GND
```

I2C1 设备地址（程序中定义，不可冲突）：

| 设备     | 7-bit 地址 | 8-bit 写地址     |
|---------|-----------|-----------------|
| MAX30102| 0x57      | 0xAE            |
| MPU6050 | 0x68      | 0xD0            |

### I2C2 总线 — SSD1306 OLED（PB10/PB11）

OLED 独占 I2C2 总线，避免与 100Hz 高速采样的 MAX30102 竞争带宽：

```
STM32 PB10 ──── SSD1306 SCL
STM32 PB11 ──── SSD1306 SDA
3.3V       ──── SSD1306 VCC
GND        ──── SSD1306 GND
```

| 设备     | 7-bit 地址 | 8-bit 写地址     |
|---------|-----------|-----------------|
| SSD1306 | 0x3C      | 0x78            |

**重要**: PB8、PB9、PB10、PB11 各需要一个 4.7kΩ 电阻上拉到 3.3V。I2C 空闲时 SCL/SDA 应为 3.3V（高电平），如果为 0V 说明上拉电阻虚焊或某设备将总线拉死。

### UART1 — HC-05 蓝牙模块

```
STM32 PA9  ──── HC-05 RX
STM32 PA10 ──── HC-05 TX
3.3V       ──── HC-05 VCC
GND        ──── HC-05 GND
```

HC-05 工作于 3.3V 逻辑电平，与 STM32 直连无需电平转换。蓝牙默认波特率 9600。

### UART2 — ASR PRO 语音识别

```
STM32 PA2  ──── ASR PRO RX（或 SU-03T 的 B6/B7，取决于固件配置）
STM32 PA3  ──── ASR PRO TX
5V         ──── ASR PRO VCC（注意：语音模块通常是 5V 供电）
GND        ──── ASR PRO GND
```

> ASR PRO 模块通常工作在 5V，但它的 TX 引脚输出一般是 3.3V 电平，可直接接 STM32。
> 如果不确定，用万用表测量模块 TX 引脚的逻辑高电平电压，超过 3.6V 则需串联一个 1kΩ 电阻。

### DS18B20 温度传感器 — 1-Wire

```
                                ┌──────┐
                                │DS18B20│
                                │ (正面)│
DS18B20 引脚:                    │1 2 3 │
  1 = GND  ──── GND              └─┬──┬─┘
  2 = DQ   ──── STM32 PA1          │  │
  3 = VCC  ──── 3.3V            ┌─┘  └─┐
                                 │     │
                            PA1 接引脚2

           3.3V
            │
           ┌┴┐
           │ │ 4.7kΩ  ← 必需！PA1 与 3.3V 之间
           │ │
           └┬┘
            │
            └──── PA1 (DS18B20 DQ)
```

程序使用外部供电三线制接法（VCC、DQ、GND 全部接上），不支持寄生供电模式。

> DS18B20_ReadData 返回值：`ERR_CRC`(-3) 校验失败、`ERR_TIMEOUT`(-2) 总线无响应（见 errors.h）。
> main.c 以 `== 0` 判断成功，失败时显示 `--.- C`。

### DS1302 RTC 时钟模块

```
STM32 PB1  ──── DS1302 CLK
STM32 PB14 ──── DS1302 DAT
STM32 PB13 ──── DS1302 RST（模块上标注为 RST/CE）
3.3V       ──── DS1302 VCC
GND        ──── DS1302 GND
```

DS1302 模块板上已经有上拉电阻和晶振（32.768kHz），无需外接组件。安装 CR2032 纽扣电池后，断电也不会走时丢失。上电时 main() 会自检 DS1302 并经 UART1 输出结果。

### 按键 — PA0 (WK_UP)

一个按键，控制翻页：

```
STM32 PA0 ────┬──── 按键一脚 (翻页)
              │
3.3V      ────┴──── 按键另一脚
```

按下 → 对应引脚读为高电平（PA0 配置为开漏输出低电平，模拟强下拉），程序做了无阻塞消抖（50ms 周期采样）和 300ms 防连按。

## 首次使用步骤

1. 接好所有模块的电源线和信号线。
2. 逐个模块上电验证（先把 I2C 之外的模块一个个通电，最后再接 OLED/MPU6050/MAX30102）。
3. 用 ST-Link 或串口下载程序到 STM32F103。
4. 上电后 OLED 显示主页（时间 + 语音指令指南）。
5. 把手指放到 MAX30102 传感器上稳定 10 秒以上，心率数据会逐渐出现。
6. 把 DS18B20 贴在手腕皮肤上，体温数据约 30 秒后出现在第 5 页。
7. 手机打开蓝牙，搜索并配对 HC-05（默认名称为 HC-05，配对码 1234）。
8. 在手机蓝牙串口 APP 上连接，每 2 秒会收到一条 JSON 数据推送。

## 操作说明

### 页面切换

显示屏共 6 个页面，按硬件按键（PA0 WK_UP 翻页）或发送语音命令切换：

| 页码 | 显示内容             | 说明                            |
|------|---------------------|---------------------------------|
| 0    | 主页                 | 大号时间 + 语音指令指南          |
| 1    | 心率（HeartRate）    | 单位 bpm，手指需稳定放在传感器上    |
| 2    | 血氧（SpO2）         | 单位 %，正常值 95–100            |
| 3    | 步数（Steps）        | 走路时自动累计                   |
| 4    | 体温（BodyTemp）     | 补偿后的体表估计温度，单位 °C      |
| 5    | 活动状态（Activity）  | RESTING / WALKING / RUNNING     |

### 心率血氧使用方式

MAX30102 传感器需要手指**稳定按压**在 LED 上，不能移动：
- 手指略施压力，覆盖光电传感器窗口
- 保持静止至少 10 秒不动
- 心率在稳定后约 5-8 秒更新一次
- 手指抖动或压力不均会导致数据不准或显示 0
- 手指离开后约 3 秒（窗口排空 + 保持计数），读数自动归零

> 心率和血氧计算基于 IR/Red 光的 AC/DC 比值。程序使用 100Hz 采样率，
> 带通滤波（HP 0.5Hz + LP 5Hz）提取脉搏波形，动态阈值检测峰值。

### 计步器使用方式

基于 MPU6050 加速度数据自动识别：
- 将设备佩戴在手腕上正常走路即可
- 通过加速度幅值减去重力分量检测步态
- 自适应阈值：静止时阈值自动调低，运动时自动调高
- 最小步间隔 300ms（允许 ~200 步/分钟，兼顾跑步）
- 连续步态确认：3 秒窗口内至少 2 步才开始累计，过滤单次碰触

### 温度传感器使用方式

DS18B20 需要贴在手腕皮肤上：
- TO-92 封装金属面朝皮肤
- 可用医用胶带固定
- 读取周期约 1 秒（5 × 200ms 传感器任务周期：启动转换 → 等待 750ms → 读取）
- CRC 校验失败（接触不良或线太长时会出现）时丢弃本次读数并显示 "--.- C"
- 体温补偿算法：根据 MPU6050 板级温度（作为环境温度参考）自动调整皮肤到核心的温差补偿量

## 软件架构

### 代码分层

```
应用层        main.c (任务编排)          ← "做什么"
算法层        algorithms.c              ← "怎么算" (可在 PC 上单元测试)
驱动层        max30102.c / mpu6050.c…   ← "怎么读"
硬件抽象      i2c.c / uart.c            ← "怎么传"
                      │
            STM32 StdPeriph / CMSIS ← 寄存器
```

### FreeRTOS 任务

| 任务名    | 堆栈(字) | 优先级 | 周期  | 功能                                   |
|----------|---------|-------|------|----------------------------------------|
| Sensors  | 512     | 3     | 200ms| 读 MAX30102 FIFO、MPU6050、DS18B20；喂看门狗 |
| Display  | 512     | 2     | 50ms | 刷新 OLED（脏页优化）、按键/语音翻页         |
| Voice    | 384     | 2     | 10ms | 轮询 UART2 语音指令，入队翻页请求           |
| BT       | 384     | 2     | 20ms | 每 2 秒经 UART1 广播 JSON 健康数据          |

### 可靠性设计

- **双 I2C 总线**：I2C1（传感器）与 I2C2（OLED）分离，各自互斥锁保护，避免 100Hz PPG 与显示刷新争带宽
- **I2C 自恢复**：任何 I2C 错误自动复位总线（DeInit + ReInit），单次操作 50ms 超时
- **看门狗**：IWDG 4 秒超时，Sensors 任务每周期喂狗；总线死锁/任务挂起自动复位
- **栈溢出诊断**：`vApplicationStackOverflowHook` 经 UART1 输出任务名（115200bps）
- **断言诊断**：`configASSERT` 失败输出文件名:行号后等看门狗复位
- **空闲休眠**：空闲任务 WFI 休眠，降低空闲功耗（后续可升级 STOP 模式）
- **统一错误码**：[errors.h](crouse.h/errors.h) 定义 ERR_IO / ERR_TIMEOUT / ERR_CRC 等

## 蓝牙数据格式

HC-05 每 **2 秒** 自动上报一条 JSON（单向广播，不接收命令）：

```json
{"hr":72,"spo2":98,"steps":1234,"temp":36.50}
```

| 字段   | 含义     | 单位  |
|-------|---------|-------|
| hr    | 心率     | bpm   |
| spo2  | 血氧     | %     |
| steps | 步数     | 步    |
| temp  | 体温     | °C    |

> 体温无效时 temp 值为 0.00。RTC 时间由语音命令或出厂预设设置。

## 语音命令

ASR PRO 模块通过 UART2（PA2/PA3，**115200bps**）发送单字节指令：

| 命令码 | 功能     | 建议语音词条       | 跳转页 |
|-------|---------|-------------------|-------|
| 0x01  | 显示心率  | "查看心率"         | 1     |
| 0x02  | 显示步数  | "查看步数"         | 3     |
| 0x03  | 清零步数  | "归零步数"（清零并跳转）| 3 |
| 0x04  | 显示血氧  | "查看血氧"         | 2     |
| 0x05  | 显示体温  | "查看体温"         | 4     |
| 0x06  | 查看状态  | "查看状态"         | 5     |

> 语音任务只把目标页号入队，显示任务取出后跳页刷新——避免语音画的屏幕被周期刷新覆盖。
> 命令码必须与 ASR PRO 固件烧录的词条映射一致（[asr_pro.h](crouse.h/asr_pro.h)）。

## 常见问题

**Q: OLED 不显示**

A: OLED 使用 I2C2 总线（PB10/PB11），检查这两个引脚的 4.7kΩ 上拉电阻是否焊接。用万用表测量，SCL/SDA 在空闲时应为 3.3V（高电平）。如果为 0V，说明上拉电阻虚焊或 I2C 器件将总线拉死。

**Q: 心率一直显示 0**

A: 手指需要**完全覆盖** MAX30102 的 LED 和光电二极管窗口，保持静止。检查 MAX30102 板上的红光 LED 是否有微弱红光闪烁（表示激光正常点亮）。如果没有，说明 I2C 通信失败或模块未初始化成功。

**Q: 血氧显示固定 50 或 100**

A: 血氧计算公式中的 R 值超出了合理范围（因为 IR/Red 信号质量不足导致）。手指压力太大或太小都可能造成。尝试调整手指按压的力度——以刚好遮挡光为佳，不要太用力。

**Q: 体温波动大**

A: DS18B20 是接触式传感器，需要与皮肤连续紧密接触。如果贴得不紧或中间有空气间隙，会受到环境气温的显著影响。建议用医用胶带贴紧。

**Q: HC-05 连不上手机**

A:
1. HC-05 STATE 灯是否为慢闪（等待配对）？
2. 如果常亮，说明它已连到另一个设备，需要断开已有连接。
3. 如果快闪（每秒两次），说明已进入 AT 模式，需要重新上电。
4. 必须按住 HC-05 模块上的小按键不放再上电，才能进入 AT 模式修改参数。

**Q: ST-Link 下载后程序不运行**

A: 检查 BOOT0 跳线是否为 0（GND）。BOOT0=1 时进入串口下载模式，不会执行 Flash 中的程序。下载完成后将 BOOT0 接回 GND 并复位。

**Q: 堆栈溢出**

A: 程序在 `vApplicationStackOverflowHook` 中通过 UART1 输出 "STACK OVERFLOW: <任务名>"。用 USB-TTL 接 PA9 查看。如果出现此信息，需增大对应任务的堆栈大小（[main.c](crouse.c/main.c) 中 `xTaskCreate` 的第 3 个参数）。

**Q: MAX30102 FIFO 溢出**

A: `vTaskSensors` 每 200ms 读取一次 MAX30102。100Hz × 0.2s = 20 个样本。MAX30102 FIFO 容量 32 个样本，留有约 60% 余量。如果操作系统延时抖动导致读取超过 320ms 间隔，FIFO 溢出标志置位后该帧被丢弃（不输出错数据），下一帧恢复正常。
